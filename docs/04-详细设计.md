# 4. 详细设计

## 4.1 应用入口

### `src/main.js`

```
职责：创建 Vue 应用实例，挂载路由和全局样式
流程：
  1. import createApp from 'vue'
  2. import App 根组件
  3. import router 路由实例
  4. import global.css 全局样式
  5. app.use(router)     → 注册路由插件
  6. app.mount('#app')   → 挂载到 DOM
```

### `src/App.vue`

```
职责：应用根组件
模板结构：
  <div id="app-root">
    <router-view :key="$route.fullPath" />   ← 路由视图（key 强制刷新）
    <ToastContainer />                        ← 全局 Toast
  </div>
说明：
  - key="$route.fullPath" 确保路由切换时完全重新渲染
  - ToastContainer 全局常驻，通过 window 事件接收消息
```

## 4.2 路由系统

### `src/router/index.js`

**核心设计**：采用「自动发现 + 集中注册」的路由管理模式。

```
执行流程：
  1. 创建空的 packageRoutes[] 数组
  2. 导出 registerPackage(routes) 函数供各角色包调用
  3. 使用 require.context('@packages', true, /manifest\.js$/)
     → Webpack 在编译时扫描 packages/ 下所有 manifest.js
     → 逐个 require 执行，触发 registerPackage() 注册路由
  4. 创建 Router 实例：
     routes = [
       ...packageRoutes,           ← 所有角色包路由
       { path: '/', CharacterList },
       { path: '/character/:id', CharacterDetail },
       { path: '/:pathMatch(.*)*', redirect: '/' }
     ]
  5. 配置 scrollBehavior → 平滑滚动到顶部
```

**设计优势**：
- 新增角色只需创建 package 目录并编写 manifest.js，无需修改路由文件
- 编译时静态分析，不影响运行时性能
- 角色包完全解耦，可独立开发测试

## 4.3 数据层

### `src/api/character.js` — 角色注册表

```
职责：管理所有角色的卡片展示数据（首页用）
导出函数：
  - getCharacterList() → characters[]    获取全部角色列表
  - getCharacterById(id) → character     按 ID 查找角色

数据结构（每个角色）：
  {
    id: string,          // 路由标识，对应 /character/:id
    name: string,        // 中文名
    nameSub: string,     // 外文名
    series: string,      // 所属作品
    image: string,       // 立绘（Webpack import 的资源路径）
    hasDetail: boolean,  // 是否有独立详情页
    tags: [{ text, cls }]
  }

说明：
  - hasDetail=true 的角色点击卡片跳转到独立详情页
  - hasDetail=false 的角色点击弹出 Toast "角色页面即将上线"
  - 当前所有已实装角色 hasDetail 均为 true
```

### 各角色 `api/index.js` — 角色完整数据

```
职责：提供单个角色详情页所需的全部数据
导入方式：Detail.vue 中直接 import data from '../api/index.js'
数据内容：
  - 基础信息（名字、称号、作品、标签等）
  - 信息卡片（生日、血型、身高、声优等 9 项）
  - 标签页内容（性格、外貌、背景、剧情等 4 个 Tab）
  - 能力列表（4 项能力，含等级和描述）
  - 关系列表（3~4 个关系角色）
  - 名言引用

富文本支持：
  - content 和 desc 字段支持 HTML
  - 自定义高亮标签：<span class="highlight">紫色高亮</span>
  - 自定义高亮标签：<span class="highlight-pink">粉色高亮</span>
```

## 4.6 Toast 通知系统

```
架构：
  ┌──────────────┐     window event      ┌──────────────────┐
  │  触发方       │  ──────────────────→  │ ToastContainer   │
  │ (任意组件)    │  CustomEvent('toast') │ (App.vue 内)     │
  │              │  { message, type }    │                  │
  └──────────────┘                        └──────────────────┘
                                                 │
                                                 │ useToast()
                                                 │ (共享 ref)
                                                 ▼
                                          ┌──────────────┐
                                          │ toasts ref[] │
                                          │ 自动 3s 移除  │
                                          └──────────────┘

使用方式：
  // 方式1：在组件内直接调用
  import { useToast } from '@/util/toast'
  const { showToast } = useToast()
  showToast('消息内容', 'info')  // type: 'success' | 'info' | 'error'

  // 方式2：通过 window 事件（跨组件/无 Vue 上下文时）
  window.dispatchEvent(new CustomEvent('toast', {
    detail: { message: '角色页面即将上线', type: 'info' }
  }))

Toast 类型：
  success → ✅ 绿色背景 (#16a34a)
  info    → ℹ️ 紫色背景 (#a855f7)
  error   → ❌ 红色背景 (#ef4444)
```

## 4.8 新增角色流程

```
步骤 1：创建角色包目录
  packages/<id>/
  ├── manifest.js
  ├── api/index.js
  ├── views/Detail.vue
  └── images/

步骤 2：编写 manifest.js
  - 定义路由路径 /character/<id>
  - 组件懒加载 () => import('./views/Detail.vue')

步骤 3：编写 api/index.js
  - 填写角色基础数据（名字、称号、作品等）
  - 填写信息卡片（9项）
  - 填写标签页内容（性格、外貌、背景、剧情）
  - 填写能力和关系

步骤 4：复制并修改 Detail.vue
  - 从已有角色复制模板
  - 修改 CSS 命名空间和主题色
  - 调整 Tab 组合（有番剧/游戏则加对应 Tab）
  - import 图片资源，配置 galleryItems

步骤 5：放入图片资源
  - 1.jpg（立绘，必需）
  - 2~N.jpg（美图）
  - a.jpg / b.jpg（封面）
  - sp1~N.jpg（视频封面）

步骤 6：在 src/api/character.js 中注册
  - 添加 import 立绘
  - 添加角色到 characters 数组
  - 设置 hasDetail: true

路由自动发现无需手动配置。
```
