# 4. 详细设计

## 4.1 应用入口

### `src/main.js`

```
职责：创建 Vue 应用实例，挂载路由和全局样式
流程：
  1. import createApp from 'vue'
  2. import App 根组件
  3. import router 路由实例
  4. import global.css 全局样式
  5. import detail-enhancements.css 详情页增强层
  6. app.use(router)     → 注册路由插件
  7. app.mount('#app')   → 挂载到 DOM
```

### `src/App.vue`

```
职责：应用根组件
模板结构：
  <div id="app-root">
    <router-view :key="$route.fullPath" />   ← 路由视图（key 强制刷新）
    <ToastContainer />                        ← 全局 Toast
  </div>
说明：
  - key="$route.fullPath" 确保路由切换时完全重新渲染
  - ToastContainer 全局常驻，通过 window 事件接收消息
```

## 4.2 路由系统

### `src/router/index.js`

**核心设计**：全部角色共用一条详情路由 `/<...>/character/:id`，由页面组件根据 `id` 懒加载对应数据包。

```
执行流程：
  1. 懒加载三个页面组件：
       CharacterList  = () => import('@/pages/CharacterList.vue')
       CharacterDetail = () => import('@/pages/CharacterDetail.vue')
       NotFound       = () => import('@/pages/NotFound.vue')
  2. 创建 Router 实例（Hash 模式）：
       routes = [
         { path: '/',                CharacterList,   meta: { title: SITE_TITLE } },
         { path: '/character/:id',   CharacterDetail, meta: { title: SITE_TITLE } },
         { path: '/:pathMatch(.*)*', NotFound,        meta: { title: '页面未找到 — YuanHuaWiki' } }
       ]
  3. 配置 scrollBehavior → 平滑滚动到顶部
  4. 注册 afterEach 钩子 → 依据 meta.title 更新 document.title
```

**标题的两级策略**：

| 层级 | 位置 | 效果 |
|------|------|------|
| 路由级 | `router.afterEach` | 进入任何路由先设置 `meta.title`（列表页 = 站点名，404 = 页面未找到） |
| 数据级 | `CharacterDetail.vue` 数据加载完成后 | 覆盖为 `角色名 \| 作品名 — YuanHuaWiki` |

**设计优势**：
- 一条详情路由覆盖全部角色，路由表不再随角色数量增长
- 每个角色数据独立分包（Webpack 动态 import），首屏只下载首页所需 chunk
- 新增角色只需新增数据包 + 登记一行 loader，无需触碰路由文件

## 4.3 数据层

### `src/api/character.js` — 列表注册表 + 懒加载映射

```
职责：
  1. 首页卡片数据（同步、轻量）
  2. 详情页数据的懒加载入口

导出：
  - getCharacterList() → characters[]      获取全部角色列表（同步）
  - getCharacterById(id) → character|null  按 ID 查找列表项
  - hasCharacterData(id) → boolean         该角色是否有详情数据包
  - loadCharacter(id) → Promise<object|null> 异步加载角色完整数据

列表项数据结构：
  {
    id: string,          // 路由标识，对应 /character/:id
    name: string,        // 中文名
    nameSub: string,     // 外文名
    series: string,      // 所属作品
    image: string,       // 立绘（Webpack import 的资源路径）
    hasDetail: boolean,  // 是否有详情数据包
    tags: [{ text, cls }]
  }

懒加载映射：
  const loaders = {
    rem: () => import('@packages/rem/api/index.js'),
    /* ...每位角色一行... */
  }
  说明：
    - 每个 import() 生成独立 chunk，只有访问对应角色时才会下载
    - loadCharacter 对异常做了容错，失败时 console.error 并返回 null
```

### 各角色 `api/index.js` — 角色完整数据

```
职责：提供单个角色详情页所需的全部数据
导入方式：由 loadCharacter(id) 动态 import，以 props.data 传给 CharacterDetailLayout
数据分组：
  1. 基础信息    id / name / nameSub / nameJp / title / series / image / tags
  2. 资料内容    info（信息卡片）、tabs（子标签页，含名言）、abilities、relationships
  3. 站长评价    review（仅部分角色有）
  4. 布局数据    placeholderEmoji / avatarSize / avatarBg / mainTabs / theme / works / gallery / videos

富文本支持：
  - content、desc 字段支持 HTML
  - 自定义高亮标签：<span class="highlight">紫色高亮</span>
  - 自定义高亮标签：<span class="highlight-pink">粉色高亮</span>
```

### 4.4.2 角色详情入口 — CharacterDetail.vue

```
文件路径：src/pages/CharacterDetail.vue
路由路径：/character/:id
组件名：CharacterDetail

职责：加载数据 + 三种状态的切换（本身不含详情模板）

模板逻辑：
  <CharacterDetailLayout v-if="character" :data="character" />
  <NotFound v-else-if="loaded" />              ← 数据包里没有该 id
  <div v-else class="detail-loading">…</div>   ← 加载中（旋转指示器）

核心逻辑：
  - const route = useRoute()
  - character = ref(null)；loaded = ref(false)
  - watch(() => route.params.id, id => load(id), { immediate: true })
  - load(id)：
      loaded = false
      character = await loadCharacter(id)
      loaded = true
      document.title = character
        ? `${character.name} | ${character.series} — YuanHuaWiki`
        : SITE_TITLE

支持路由内切换角色（watch 监听 params.id），无需刷新页面。
```

## 4.6 Toast 通知系统

```
架构：
  ┌──────────────┐     window event      ┌──────────────────┐
  │  触发方       │  ──────────────────→  │ ToastContainer   │
  │ (任意组件)    │  CustomEvent('toast') │ (App.vue 内)     │
  │              │  { message, type }    │                  │
  └──────────────┘                        └──────────────────┘

使用方式：
  // 方式 1：组件内调用
  import { useToast } from '@/util/toast'
  const { showToast } = useToast()
  showToast('消息内容', 'info')   // type: 'success' | 'info' | 'error'

  // 方式 2：window 事件（无 Vue 上下文时）
  window.dispatchEvent(new CustomEvent('toast', {
    detail: { message: '角色页面即将上线', type: 'info' }
  }))

Toast 类型：
  success → ✅ 绿色 (#16a34a)   info → ℹ️ 紫色 (#a855f7)   error → ❌ 红色 (#ef4444)
```

## 4.8 新增角色流程

```
步骤 1：创建角色包目录
  packages/<id>/
  ├── api/index.js
  └── images/

步骤 2：编写 api/index.js
  ① 基础信息：id / name / nameSub / nameJp / title / series / image / tags
  ② 资料内容：info（9 项左右）、tabs（性格/外貌/背景/剧情）、abilities、relationships
  ③ 布局数据：
      - mainTabs：决定详情页出现哪些 Tab
      - theme：从已有角色复制后改色（或全部省略使用默认蓝色系）
      - works.anime / works.game：作品卡片数组（无则留空数组）
      - gallery：图片项数组（无图可用 emoji 占位项）
      - videos：视频卡片数组
      - avatarSize / avatarBg / placeholderEmoji：头像展示参数

步骤 3：放入图片资源（文件名固定约定）
  1.jpg（立绘，必需）、2~N.jpg（美图）、a.jpg（番剧封面）、b.jpg（游戏封面）、sp1~N.jpg（视频封面）
  注意：b2.jpg、sp5~N.jpg 等额外封面按 works/videos 中的引用顺序命名

步骤 4：在 src/api/character.js 中登记
  ① import 立绘：import <id>Img from '@packages/<id>/images/1.jpg'
  ② characters 数组追加列表项（含 tags、hasDetail: true）
  ③ loaders 表追加一行：<id>: () => import('@packages/<id>/api/index.js')

步骤 5：（可选）在 src/styles/detail-enhancements.css 追加 .<id>-page 的 --detail-* 变量

路由无需任何修改，详情页自动可用。
```
