## 2.3 路径别名

| 别名 | 实际路径 | 用途 |
|------|----------|------|
| `@` | `src/` | 源码目录 |
| `@packages` | `packages/` | 角色包目录 |
| `@assets` | `assets/` | 公共资源目录 |

## 2.4 构建与运行

```bash
# 开发模式（端口 3000）
npm run dev

# 生产构建（输出到 dist/）
npm run build

# 代码检查
npm run lint
```

**构建配置要点**（`vue.config.js`）：
- `publicPath: '/'`：根路径部署
- `outputDir: 'dist'`：构建输出目录
- `assetsDir: 'assets'`：静态资源子目录
- `devServer.proxy`：`/api` 代理到 `localhost:8080`（预留后端接口）
- `configureWebpack.resolve.alias`：配置 `@`、`@packages`、`@assets` 路径别名
