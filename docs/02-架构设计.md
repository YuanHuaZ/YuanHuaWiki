## 2.2 目录结构

```
YuanHuaWiki/
├── public/                          # 静态资源
│   └── index.html                   # HTML 入口模板（标题取 <%= VUE_APP_TITLE %>）
├── src/                             # 应用源码
│   ├── main.js                      # 应用入口（创建 Vue 实例、挂载路由）
│   ├── App.vue                      # 根组件（RouterView + ToastContainer）
│   ├── api/
│   │   └── character.js             # 卡片汇总（各角色 meta）+ 详情数据懒加载映射表
│   ├── router/
│   │   └── index.js                 # 路由配置（统一详情路由 + 标题钩子）
│   ├── pages/
│   │   ├── CharacterList.vue        # 首页 — 角色列表（卡片网格 + 搜索）
│   │   ├── CharacterDetail.vue      # 角色详情入口（加载数据 + 状态兜底）
│   │   └── NotFound.vue             # 404 页面
│   ├── components/
│   │   └── ToastContainer.vue       # 全局 Toast 通知容器
│   ├── util/
│   │   └── toast.js                 # Toast 工具函数（useToast composable）
│   └── styles/
│       ├── global.css               # 全局样式（Reset、动画、通用组件样式、标签、按钮）
│       └── detail-enhancements.css  # 详情页统一增强层（--detail-* 变量按角色覆盖）
├── packages/                        # 角色包目录（核心）
│   ├── shared/                      # 共享组件
│   │   └── components/
│   │       ├── AppHeader/index.vue          # 全局顶栏（固定定位，滚动变色）

│   │       ├── CharacterCard/index.vue      # 角色卡片组件
│   │       ├── CharacterDetailLayout/index.vue # 详情页统一布局（模板 + 样式 + 主题变量）

│   ├── rem/                         # 示例角色包 — 雷姆
│   │   ├── meta.js                  # 角色身份信息（卡片与详情页唯一来源）
│   │   ├── api/index.js             # 角色完整数据（含 theme / works / gallery / videos）

```

> 说明：角色包不再包含 `manifest.js` 与 `views/Detail.vue`，详情页模板由 `shared` 下的 `CharacterDetailLayout` 统一提供。
> 角色身份信息（id / name / nameSub / series / seriesShort / cardBg / cardSize / image / tags）统一放在 `packages/<id>/meta.js`，
> 由 `src/api/character.js` 与同目录 `api/index.js` 共用，避免两处各写一份导致漂移。

## 2.3 路径别名

| 别名 | 实际路径 | 用途 |
|------|----------|------|
| `@` | `src/` | 源码目录 |
| `@packages` | `packages/` | 角色包目录 |

## 2.4 构建与运行

```bash
# 开发模式（端口 3000）
npm run dev

# 生产构建（输出到 dist/）
npm run build
```

**构建配置要点**（`vue.config.js`）：

| 配置项 | 值 | 说明 |
|--------|-----|------|
| `publicPath` | `/YuanHuaWiki/` | 子路径部署（适配 GitHub Pages 项目页） |
| `outputDir` | `dist` | 构建输出目录 |
| `assetsDir` | `assets` | 静态资源子目录 |
| `devServer.port` | `3000` | 开发端口 |
| `resolve.alias` | `@` / `@packages` | 路径别名 |

> 说明：`package.json` 中保留 `lint` 脚本（`vue-cli-service lint`），但项目当前未安装 ESLint 及其配置，
> 直接执行会报错；如需启用需先安装 `eslint`、`eslint-plugin-vue`、`@vue/cli-plugin-eslint` 并生成 `.eslintrc.js`。
