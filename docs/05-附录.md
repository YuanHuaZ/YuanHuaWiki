## 5.4 动画列表

| 名称 | 效果 | 用途 |
|------|------|------|
| `fadeIn` | 淡入 | 通用入场 |
| `slideUp` | 从下方滑入 | 内容区块入场 |
| `slideDown` | 从上方滑入 | Toast 通知 |
| `float` | 上下浮动 | 光晕装饰 |
| `pixelFloat` | 浮动 + 旋转 | 粒子动画 |
| `spinSlow` | 缓慢旋转 | 头像光环 |
| `cardIn` | 淡入 + 上移 + 缩放 | 卡片入场 |
| `shimmer` | 渐变位移 | Footer 顶部彩线 |
| `pulseGlow` | 脉冲发光 | Badge 圆点 |

## 5.5 响应式断点

| 断点 | 布局变化 |
|------|----------|
| `>1200px` | 角色卡片 4列 |
| `≤1200px` | 角色卡片 3列 |
| `≤1024px` | Hero 单列居中，Info 2列 |
| `≤768px` | 角色卡片 2列，番剧卡单列，能力 1列 |
| `≤640px` | Info 1列，画廊 2列，视频 1列 |
| `≤480px` | 角色卡片 1列，按钮最小高度 44px |
