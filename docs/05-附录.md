## 5.1.1 详情页主题变量

`CharacterDetailLayout` 会把角色 `api/index.js` 中 `theme` 对象的每个字段映射为 CSS 变量，
命名规则：`camelCase` → `--acc-kebab-case`（如 `heroBg` → `--acc-hero-bg`）。

| theme 字段 | CSS 变量 | 用途 |
|------|-----------|------|
| `heroBg` | `--acc-hero-bg` | Hero 区域背景渐变 |
| `glow1` / `glow2` | `--acc-glow-1` / `--acc-glow-2` | 两处光晕颜色 |
| `particleBg` | `--acc-particle-bg` | 粒子颜色 |
| `gridImage` | `--acc-grid-image` | 网格线纹理 |
| `badgeBg` / `badgeBorder` / `badgeColor` / `badgeShadow` | `--acc-badge-*` | 作品徽章样式 |
| `dotBg` | `--acc-dot-bg` | 徽章圆点颜色 |
| `nameGrad` / `nameColor` | `--acc-name-grad` / `--acc-name-color` | 角色名渐变或纯色 |
| `nameSubColor` | `--acc-name-sub-color` | 外文名颜色 |
| `titleBadgeBg` / `titleBadgeBorder` / `titleBadgeColor` | `--acc-title-badge-*` | 称号徽章样式 |
| `tagBg` / `tagBorder` / `tagColor` | `--acc-tag-*` | 标签样式 |
| `ringGrad` | `--acc-ring-grad` | 头像光环渐变 |
| `avatarShadow` | `--acc-avatar-shadow` | 头像外发光 |
| `placeholderBg` / `emojiShadow` | `--acc-placeholder-bg` / `--acc-emoji-shadow` | 无立绘时的占位样式 |
| `videoPlayBg` / `videoFallback` | `--acc-video-play-bg` / `--acc-video-fallback` | 视频播放按钮与封面兜底 |
| `reviewBg` / `reviewDots` / `reviewOverlay` / `reviewAvatarShadow` / `reviewLabelBg` / `reviewLabelColor` / `reviewDescColor` / `reviewBodyBorder` | `--acc-review-*` | 评价板块样式（仅含评价 Tab 的角色） |

组件内所有颜色均使用 `var(--acc-xxx, 兜底值)` 写法，字段缺失时自动回退到默认蓝色系。

## 5.1.2 全局增强变量

`src/styles/detail-enhancements.css` 为所有详情页提供统一的视觉增强层，通过 `.<id>-page` 类注入：

```css
.rem-page {
  --detail-accent: #5e9dd6;        /* 强调色 */
  --detail-accent-soft: rgba(...);  /* 强调色浅底 */
  --detail-accent-line: rgba(...);  /* 强调色描边 */
  --detail-hero-base: #1d3957;      /* Hero 基底色 */
  --detail-hero-mid: #1f2d47;       /* Hero 过渡色 */
}
```

注意：`komari` 包的类名是 `.komori-page`（历史命名），新增角色时保持一致即可。

## 5.4 动画列表

| 名称 | 效果 | 用途 |
|------|------|------|
| `fadeIn` | 淡入 | 通用入场 |

## 5.5 响应式断点

| 断点 | 布局变化 |
|------|----------|
| `>1200px` | 角色卡片 4列 |
| `≤1200px` | 角色卡片 3列 |
| `≤1024px` | Hero 单列居中，Info 2列 |
| `≤768px` | 角色卡片 2列，番剧卡单列，能力 1列 |
| `≤640px` | Info 1列，画廊 2列，视频 1列 |
| `≤480px` | 角色卡片 1列，按钮最小高度 44px |
