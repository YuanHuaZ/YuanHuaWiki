# 3. 概要设计

## 3.1 整体模块划分

```
┌────────────────────────────────────────────────────────┐
│                      应用层                             │
│  ┌──────────┐  ┌──────────────┐  ┌──────────────────┐ │
│  │ 框架页面  │  │  角色数据包   │  │   共享组件库      │ │
│  │ (Pages)  │  │ (Packages)   │  │  (Shared)        │ │
│  └────┬─────┘  └──────┬───────┘  └────────┬─────────┘ │
│       │               │                    │           │
│  ┌────┴───────────────┴────────────────────┴─────────┐ │
```

## 3.2 页面路由设计

| 路径 | 组件 | 说明 |
|------|------|------|
| `/` | CharacterList | 首页，角色卡片网格 + 搜索 |
| `/character/:id` | CharacterDetail | 全部角色共用的详情入口，按 `id` 加载对应数据包 |
| `/:pathMatch(.*)*` | NotFound | 404 页面 |

> 路由使用 `createWebHashHistory`（Hash 模式），实际访问形如 `/#/character/rem`。

**路由与标题机制**：

```javascript
// src/router/index.js
const router = createRouter({
  history: createWebHashHistory(),
  routes: [
    { path: '/',                 name: 'CharacterList',   component: CharacterList,   meta: { title: SITE_TITLE } },
    { path: '/character/:id',    name: 'CharacterDetail', component: CharacterDetail, meta: { title: SITE_TITLE } },
    { path: '/:pathMatch(.*)*',  name: 'NotFound',        component: NotFound,        meta: { title: '页面未找到 — YuanHuaWiki' } }
  ],
  scrollBehavior() { return { top: 0, behavior: 'smooth' } }
})

// 浏览器标签标题跟随路由
router.afterEach(to => {
  document.title = (to.meta && to.meta.title) || SITE_TITLE
})
```

**数据懒加载**（`src/api/character.js`）：

```javascript
const loaders = {
  rem: () => import('@packages/rem/api/index.js'),
  nanami: () => import('@packages/nanami/api/index.js'),
  /* ...每位角色一行... */
}

export async function loadCharacter(id) {
  const loader = loaders[id]
  if (!loader) return null
  const mod = await loader()
  return mod.default || mod
}
```

每行 `import()` 会被 Webpack 切成独立 chunk，实现按需加载；
角色不存在时 `loadCharacter` 返回 `null`，页面回退到 404 视图。

## 3.3 数据流设计

```
┌─────────────────────────────────────────────────────────┐
│                       数据层                             │
│                                                          │
│  ┌──────────────────┐    ┌───────────────────────────┐  │
│  │ src/api/          │    │ packages/<id>/api/index.js │  │
│  │ character.js      │    │                            │  │
│  │                   │    │ 单角色完整数据：            │  │
│  │ 列表注册表：        │    │ - 基础信息 / info / tabs    │  │
│  │ - id/name/nameSub │    │ - abilities / relationships│  │
│  │ - series/image    │    │ - theme（主题色）           │  │
│  │ - tags/hasDetail  │    │ - mainTabs（Tab 配置）      │  │
│  │                   │    │ - works（番剧/游戏卡片）     │  │
│  │ 懒加载映射表：      │    │ - gallery / videos         │  │
│  │ - loaders[id]     │    │ - avatar 相关样式参数        │  │
│  └────────┬─────────┘    └────────────┬──────────────┘  │
│           │                           │                 │
│    getCharacterList()          loadCharacter(id)        │
│    （同步，首页用）              （异步 import，详情用）    │
└───────────┼───────────────────────────┼─────────────────┘
            │                           │
     ┌──────┴──────┐          ┌─────────┴──────────┐
     │CharacterList│          │  CharacterDetail   │
     │  .vue       │          │  .vue（加载数据）    │
     │ (首页卡片)   │          │        ↓           │
     └─────────────┘          │ CharacterDetail    │
                              │ Layout（统一模板）   │
                              └────────────────────┘
```

首页只需要轻量的列表数据（同步）；详情页数据体积大且互不相干，因此按角色异步分包加载。

## 3.4 角色包规范

每个角色包遵循统一的两文件结构：

```
packages/<character-id>/
├── api/index.js        # 必需 — 角色完整数据（含主题色、Tab 配置、作品、画廊、视频）
└── images/             # 必需 — 图片资源
    ├── 1.jpg           # 立绘/头像（必需）
    ├── 2.jpg ~ N.jpg   # 美图（可选）
    ├── a.jpg           # 番剧/作品封面（可选）
    ├── b.jpg           # 游戏封面（可选）
    └── sp1~N.jpg       # 视频封面（可选）
```

> 与旧版对比：**不再需要 `manifest.js` 和 `views/Detail.vue`**，详情页模板由共享组件 `CharacterDetailLayout` 统一提供。

### api/index.js 数据结构

```javascript
export default {
  // ===== 基础信息 =====
  id: string,              // 角色唯一标识（同时也是路由参数）
  name: string,            // 中文名
  nameSub: string,         // 外文名
  nameJp: string,          // 详情页大标题（通常为中文名或日文名）
  title: string,           // 称号/头衔
  series: string,          // 所属作品
  image: string,           // 立绘图片（import 引入）
  tags: Array<{ text, cls }>,          // 标签列表（cls 见 5.2）
  info: Array<{ icon, label, value, iconClass }>,   // 基础信息卡片
  tabs: Array<{            // 资料区子标签页
    key, label, icon,
    tags: string[],        //   关键词标签
    content: string[],     //   段落（支持 HTML 与高亮标签）
    quote?, quoteAuthor?   //   名言（可选）
  }>,
  abilities: Array<{ icon, name, desc }>,           // 能力列表
  relationships: Array<{ icon, name, type, desc, cls }>, // 关系列表
  review?: string,         // 站长评价（含评价 Tab 的角色才有）

  // ===== 布局数据（CharacterDetailLayout 消费）=====
  placeholderEmoji: string,  // 无立绘时的占位 emoji
  avatarSize: string,        // 头像 background-size，如 'cover' / '150% auto'
  avatarBg: string | null,   // 头像底色，如 '#fff'
  mainTabs: Array<{ key, icon, label }>,   // 顶部 Tab 配置
  theme: { /* 主题色，键名见 5.1.1 */ },
  works: {
    anime: Array<WorkCard>,  // 相关番剧卡片（可为空数组）
    game:  Array<WorkCard>   // 相关游戏卡片（可为空数组）
  },
  gallery: Array<{ isImage, bg, badge, overlay, icon?, label? }>,
  videos:  Array<{ cover, url, title, desc }>
}
```

**WorkCard 结构**：

```javascript
{
  cover: string,                     // 封面图（import 引入）
  label: string,                     // 小标题，如 '主要登场作品' / '相关游戏 1'
  title: string,                     // 作品名
  titleJp: string,                   // 原名/日文名
  meta: Array<{ icon, label, value }>,   // 制作、播出、集数、CV 等
  desc: string,                      // 简介（支持 HTML 高亮）
  tags: Array<{ cls, text }>,        // cls: 'dark' | 'live' | 'not-available'
  action: { url, cls, icon, text } | null,  // 外链按钮（cls 决定配色，见下方映射）
  notice?: string                    // 无外链时的提示文案（如「暂无B站正版」）
}
```

**action.cls → 按钮配色映射**（布局组件 `actionVariant()`）：

| 数据中的 cls | 渲染结果 | 配色 | 使用角色 |
|------|----------|------|----------|
| `btn-bilibili` | `.btn-action.bilibili` | B 站粉 | phrolova / nanami / soyo / sagiri / rem / yoshino 等 |
| `btn-bilibili btn-steam` | `.btn-action.steam` | Steam 深蓝 | meguru |
| `btn-elaina` | `.btn-action.silver` | 银灰 | elaina |
| `btn-hutao` | `.btn-action.orange` | 橙色 | hutao |
| `btn-tomori` | `.btn-action.duo` | 蓝粉双色 | tomori |

`action` 为 `null` 且存在 `notice` 时，按钮位置渲染为红色虚线提示标签（kana / komari）。

## 3.5 共享组件设计

| 组件 | 路径 | 职责 | 通信方式 |
|------|------|------|----------|
| **AppHeader** | `shared/components/AppHeader/` | 固定顶栏，滚动时切换背景 | 监听 scroll 事件 |
| **AppFooter** | `shared/components/AppFooter/` | 底部多列链接 + 版权信息 | 无 |
| **BackToTop** | `shared/components/BackToTop/` | 返回顶部按钮，滚动 >500px 显示 | 无 |
| **HeroSection** | `shared/components/HeroSection/` | 首页 Hero 横幅 + 搜索框 | `emit('search', query)` |
| **CharacterCard** | `shared/components/CharacterCard/` | 角色卡片，点击进入详情 | `router.push()` 或 `dispatch toast` |
| **CharacterDetailLayout** | `shared/components/CharacterDetailLayout/` | 详情页统一布局（Hero、Tab、资料、作品、画廊、视频、能力、评价） | `props.data` 传入角色数据，`theme` 映射为 CSS 变量 |
| **GalleryLightbox** | `shared/components/GalleryLightbox/` | 图片灯箱预览 | 父组件通过 `ref.open(item)` 调用 |
| **ToastContainer** | `src/components/` | 全局 Toast 通知 | 监听 window `toast` 事件 |

## 3.6 角色详情页功能模块

`CharacterDetailLayout` 是所有角色共用的详情模板，Tab 列表由角色的 `mainTabs` 数据驱动：

```
┌──────────────────────────────────────────────┐
│  Hero 区域                                    │
│  - 粒子背景 + 双光晕 + 网格纹理                 │
│  - 角色名（渐变或纯色）+ 称号 + 标签            │
│  - 角色头像（旋转渐变光环 + 主题色外发光）        │
├──────────────────────────────────────────────┤
│  面包屑导航（首页 › 角色列表 › 角色名）           │
├──────────────────────────────────────────────┤
│  Tab 导航栏（sticky，由 mainTabs 渲染）          │
├──────────────────────────────────────────────┤
│  Tab 内容区（v-show 切换，保持滚动位置）          │
│                                              │
│  profile:   info 卡片网格 + tabs 子标签页       │
│  anime:     works.anime[] 作品卡片（支持多张）    │
│  game:      works.game[] 作品卡片（支持多张）     │
│  gallery:   4 列图片网格 + 点击灯箱预览           │
│  videos:    2 列视频卡片 + 外链跳转              │
│  abilities: 能力卡片 + 关系卡片                 │
│  review:    评价头图 + 正文（仅部分角色）         │
├──────────────────────────────────────────────┤
│  Footer + BackToTop + GalleryLightbox         │
└──────────────────────────────────────────────┘
```

画廊与视频封面使用 `<img loading="lazy" decoding="async">`，首屏只加载可视区域内的图片。
