## 3.2 页面路由设计

| 路径 | 页面 | 说明 |
|------|------|------|
| `/` | CharacterList | 首页，角色卡片网格 + 搜索 |
| `/character/nanami` | NanamiDetail | 七海千秋详情页 |
| `/character/phrolova` | PhrolovaDetail | 弗洛洛详情页 |
| `/character/elaina` | ElainaDetail | 伊蕾娜详情页 |
| `/character/tomori` | TomoriDetail | 友利奈绪详情页 |
| `/character/komari` | KomariDetail | 小鞠知花详情页 |
| `/character/hutao` | HutaoDetail | 胡桃详情页 |
| `/character/rem` | RemDetail | 雷姆详情页 |
| `/character/kana` | KanaDetail | 有马加奈详情页 |
| `/character/:id` | CharacterDetail | 通用占位详情页（未实装角色） |
| `/:pathMatch(.*)*` | → `/` | 404 重定向 |

**路由注册机制**：

```javascript
// src/router/index.js
// 1. 使用 require.context 自动发现所有 packages/ 下的 manifest.js
const requirePackage = require.context('@packages', true, /manifest\.js$/)
requirePackage.keys().forEach(key => requirePackage(key))

// 2. 各 manifest.js 调用 registerPackage() 注册自己的路由
// packages/nanami/manifest.js:
registerPackage([{
  path: '/character/nanami',
  name: 'NanamiDetail',
  component: () => import('./views/Detail.vue'),
  meta: { title: '七海千秋 | 超高校级的游戏玩家' }
}])

// 3. 路由表 = 包路由 + 框架页面路由
routes: [...packageRoutes, /* CharacterList, CharacterDetail, 404 */]
```

## 3.4 角色包规范

每个角色包遵循统一的四文件结构：

```
packages/<character-id>/
├── manifest.js         # 必需 — 路由注册
├── api/index.js        # 必需 — 角色数据
├── views/Detail.vue    # 必需 — 详情页组件
└── images/             # 必需 — 图片资源
    ├── 1.jpg           # 立绘（必需）
    ├── 2.jpg ~ N.jpg   # 美图（可选）
    ├── a.jpg           # 番剧/作品封面（可选）
    ├── b.jpg           # 游戏封面（可选）
    └── sp1~N.jpg       # 视频封面（可选）
```

### manifest.js 规范

```javascript
import { registerPackage } from '@/router'

const Detail = () => import('./views/Detail.vue')

registerPackage([{
  path: '/character/<id>',       // 路由路径
  name: '<Name>Detail',          // 组件名（PascalCase）
  component: Detail,
  meta: { title: '<角色名> | <称号>' }
}])

export default {
  name: '<id>',
  description: '<角色名>角色详情',
  api: () => import('./api/index.js')
}
```

### api/index.js 数据结构

```javascript
export default {
  id: string,              // 角色唯一标识
  name: string,            // 中文名
  nameSub: string,         // 外文名
  nameJp: string,          // 日文名/显示名
  title: string,           // 称号/头衔
  series: string,          // 所属作品
  image: string,           // 立绘图片（import 引入）
  tags: Array<{            // 标签列表
    text: string,          //   标签文本
    cls: string            //   CSS 类名（tag-purple, tag-pink 等）
  }>,
  info: Array<{            // 基础信息卡片
    icon: string,          //   emoji 图标
    label: string,         //   标签名
    value: string,         //   值
    iconClass: string      //   图标背景色类（purple/pink/cyan/gold/red/dark）
  }>,
  tabs: Array<{            // 标签页内容
    key: string,           //   唯一键
    label: string,         //   显示名
    icon: string,          //   emoji 图标
    tags: string[],        //   关键词标签
    content: string[],     //   段落内容（支持 HTML + 自定义高亮标签）
    quote?: string,        //   名言（可选）
    quoteAuthor?: string   //   名言出处（可选）
  }>,
  abilities: Array<{       // 能力列表
    icon: string,          //   emoji 图标
    name: string,          //   能力名
    grade: string,         //   等级（S/A/B/EX 等）
    desc: string           //   描述（支持 HTML）
  }>,
  relationships: Array<{   // 关系列表
    icon: string,          //   emoji 图标
    name: string,          //   角色名
    type: string,          //   关系类型
    desc: string,          //   描述（支持 HTML）
    cls: string            //   关系类型 CSS 类（rel-romance/rel-family/rel-friend/rel-other）
  }>
}
```

## 3.5 共享组件设计

| 组件 | 路径 | 职责 | 通信方式 |
|------|------|------|----------|
| **AppHeader** | `shared/components/AppHeader/` | 固定顶栏，滚动时切换背景 | 监听 scroll 事件 |
| **AppFooter** | `shared/components/AppFooter/` | 底部多列链接 + 版权信息 | 无 |
| **BackToTop** | `shared/components/BackToTop/` | 返回顶部按钮，滚动 >500px 显示 | 无 |
| **HeroSection** | `shared/components/HeroSection/` | 首页 Hero 横幅 + 搜索框 | `emit('search', query)` |
| **CharacterCard** | `shared/components/CharacterCard/` | 角色卡片，点击进入详情 | `router.push()` 或 `dispatch toast` |
| **GalleryLightbox** | `shared/components/GalleryLightbox/` | 图片灯箱预览 | 父组件通过 `ref.open(item)` 调用 |
| **ToastContainer** | `src/components/` | 全局 Toast 通知 | 监听 window `toast` 事件 |

## 3.6 角色详情页功能模块

每位角色的 Detail.vue 页面包含以下 Tab 模块（部分模块可选）：

```
┌──────────────────────────────────────────────┐
│  Hero 区域                                    │
│  - 粒子背景 + 光晕装饰                         │
│  - 角色名 + 称号 + 标签                        │
│  - 角色头像（带旋转渐变光环）                    │
├──────────────────────────────────────────────┤
│  面包屑导航                                    │
├──────────────────────────────────────────────┤
│  Tab 导航栏（sticky）                           │
│  [📋 角色资料] [📺 番剧] [🖼️ 画廊] [🎬 视频] [⭐ 能力] │
├──────────────────────────────────────────────┤
│                                              │
│  Tab 内容区（根据 activeMainTab 切换）           │
│                                              │
│  Profile:  信息卡片网格 + 多标签页内容           │
│  Anime:    作品封面 + 信息 + 观看链接            │
│  Game:     游戏封面 + 信息 + 购买链接            │
│  Gallery:  4列图片网格 + 点击灯箱预览            │
│  Videos:   2列视频卡片 + 外链跳转               │
│  Abilities: 能力卡片 + 关系卡片                 │
│                                              │
├──────────────────────────────────────────────┤
│  Footer + BackToTop + GalleryLightbox         │
└──────────────────────────────────────────────┘
```
