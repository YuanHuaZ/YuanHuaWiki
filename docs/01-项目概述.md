# 1. 项目概述

## 1.1 项目简介

**YuanHuaWiki** 是一个基于 Vue 3 的个人二次元角色收藏 Wiki 站点。项目以"角色"为核心单位，为每位角色提供独立的详情页面，涵盖角色资料、登场作品、图片画廊、相关视频、能力关系等多维度内容展示。

- **项目名称**：YuanHuaWiki（鸢华 Wiki）
- **版本**：2.0.0
- **定位**：个人角色收藏与展示
- **口号**：「记录我喜欢的角色，每个角色都有属于自己的故事」

## 1.2 技术栈

| 类别 | 技术 | 版本 | 说明 |
|------|------|------|------|
| 前端框架 | Vue 3 | ^3.4.0 | 使用 Composition API |
| 路由 | Vue Router 4 | ^4.3.0 | HTML5 History 模式 |
| 构建工具 | Vue CLI 5 | ^5.0.0 | 基于 Webpack |
| 编译器 | @vue/compiler-sfc | ^3.4.0 | 单文件组件编译 |
| 字体 | Google Fonts | — | Noto Sans SC / Noto Serif SC / Inter |
| 图片处理 | 本地静态资源 | — | 通过 Webpack 打包 |

## 1.3 项目特性

- **Monorepo 式角色包管理**：每个角色为独立 package，结构统一、互不干扰
- **自动路由注册**：通过 `require.context` 自动发现并加载所有角色包
- **响应式设计**：全面适配桌面端、平板、手机
- **精致动效**：粒子系统、渐变文字、悬浮光效、卡片入场动画、图片光泽扫过
- **主题色定制**：每位角色拥有独立的主题色系
- **图片画廊 + Lightbox**：支持多图浏览与大图预览
- **搜索过滤**：首页支持按角色名、作品名搜索
- **Toast 通知系统**：全局轻量级消息提示
