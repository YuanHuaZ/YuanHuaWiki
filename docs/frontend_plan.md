# 动漫角色介绍网站 - 前端页面规划文档

## 1. 页面概览

| 页面名称 | 路由 | 功能描述 | 优先级 |
|----------|------|----------|--------|
| 首页 | `/` | 轮播图、热门推荐、最新更新、分类导航 | P0 |
| 角色列表页 | `/characters` | 角色卡片列表、筛选、搜索、分页 | P0 |
| 角色详情页 | `/characters/:id` | 角色完整信息、多媒体画廊、评论区 | P0 |
| 收藏夹页 | `/favorites` | 用户收藏的角色列表、管理功能 | P0 |
| 排行榜页 | `/ranking` | 角色人气排行、投票功能 | P1 |
| 搜索结果页 | `/search?q=xxx` | 搜索结果展示、高级筛选 | P0 |
| 登录页 | `/login` | 用户登录表单 | P0 |
| 注册页 | `/register` | 用户注册表单 | P0 |

#### 2.1.2 组件组成

| 组件名称 | 功能 | 位置 |
|----------|------|------|

- 分类导航点击后跳转到角色列表页并应用筛选条件

## 4. 状态管理

### 4.1 Redux Slice 设计

| Slice名称 | 功能 | 状态字段 |
|-----------|------|----------|
| characters | 角色数据管理 | list, detail, loading, error |
| users | 用户数据管理 | currentUser, loading, error |
| favorites | 收藏数据管理 | list, loading |
| comments | 评论数据管理 | list, loading |
| ranking | 排行榜数据管理 | list, currentType |
| search | 搜索状态管理 | keyword, results |

### 4.2 Action 设计

#### characters slice

| Action | 功能 |
|--------|------|
| fetchCharacters | 获取角色列表 |
| fetchCharacterDetail | 获取角色详情 |
| likeCharacter | 点赞角色 |
| favoriteCharacter | 收藏角色 |

#### users slice

| Action | 功能 |
|--------|------|
| login | 用户登录 |
| register | 用户注册 |
| fetchCurrentUser | 获取当前用户 |
| updateUser | 更新用户信息 |
| logout | 用户登出 |

#### favorites slice

| Action | 功能 |
|--------|------|
| fetchFavorites | 获取用户收藏列表 |
| addFavorite | 添加收藏 |
| removeFavorite | 删除收藏 |

#### comments slice

| Action | 功能 |
|--------|------|
| fetchComments | 获取评论列表 |
| postComment | 发表评论 |
| likeComment | 点赞评论 |

## 8. 开发规范

### 8.1 文件命名规范

- **组件文件**: PascalCase（如 `CharacterCard.tsx`）
- **工具函数**: camelCase（如 `formatDate.ts`）
- **类型定义**: PascalCase（如 `Character.ts`）
- **状态管理**: snake_case（如 `charactersSlice.ts`）

### 8.2 代码风格

- 使用 TypeScript 严格模式
- 使用 React Hooks（避免 Class 组件）
- 使用 TailwindCSS 原子化样式
- 组件拆分原则：单一职责、可复用
- 自定义 Hooks 以 `use` 开头

### 8.3 性能优化

- 图片懒加载（使用 `loading="lazy"`）
- 列表虚拟滚动（使用 `react-window`）
- API 请求防抖（搜索功能）
- 状态缓存（使用 Redux 缓存数据）
- 组件 memo 化（使用 `React.memo`）
